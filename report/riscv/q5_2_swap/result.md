# 課題5(2) result.md

## 1. プログラムコード (swap.s)

```asm
.text
.globl _start
_start:
    li t1, 10
    li t2, 20

    mv t0, t1
    mv t1, t2
    mv t2, t0
    # ここで t1=20, t2=10 になっている

    li a0, 10          # ecall規約(Venus拡張): a0=サービス番号, exit=10
    ecall
```

## 2. 説明

RISC-Vには `xchg` のような2レジスタ直接交換命令が存在しないため、
一時レジスタ `t0` を経由した3回の `mv`（`addi rd, rs, 0` の擬似命令）で
`t1` と `t2` の内容を交換する。

```
t0 = t1       ; t0に退避
t1 = t2       ; t2の値をt1へ
t2 = t0       ; 退避しておいた元のt1の値をt2へ
```

ビルド:
```
riscv64-linux-gnu-as -o swap.o swap.s
riscv64-linux-gnu-ld -o swap swap.o
```

`ecall`の呼び出し規約はq5_1のresult.mdに記載したVenus拡張規約（`a0`=サービス番号, `a1`=引数）
に従う。実行環境の制約（実Linux上で実行すると意味が異なる点）もq5_1と同様のため、
本課題は静的なアセンブル・逆アセンブルによるバイナリ対応表の作成にとどめた。

## 4. バイナリ対応表

| アドレス | 機械語Hex | アセンブリ命令 | 説明 |
|---|---|---|---|
| 100b0 | `00a00313` | `addi t1, x0, 10`（li展開） | t1=10 |
| 100b4 | `01400393` | `addi t2, x0, 20`（li展開） | t2=20 |
| 100b8 | `00030293` | `addi t0, t1, 0`（mv展開） | t0 ← t1 (10) |
| 100bc | `00038313` | `addi t1, t2, 0`（mv展開） | t1 ← t2 (20) |
| 100c0 | `00028393` | `addi t2, t0, 0`（mv展開） | t2 ← t0 (10) |
| 100c4 | `00a00513` | `addi a0, x0, 10` | exitサービス番号(a0=サービス番号規約) |
| 100c8 | `00000073` | `ecall` | システムコール呼び出し |

交換後は `t1=20, t2=10` となり、スワップが正しく実装されていることが
命令列から確認できる。
