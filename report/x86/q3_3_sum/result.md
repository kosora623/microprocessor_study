# 課題3(3) result.md

## 1. プログラムコード (sum.asm)

```nasm
global _start
section .text
_start:
    mov rax, 0      ; sum
    mov rcx, 1      ; counter

sum_loop:
    add rax, rcx
    inc rcx
    cmp rcx, 10
    jle sum_loop

    mov rdi, rax
    mov rax, 60
    syscall
```

## 2. 説明

`rax` を合計値（初期値0）、`rcx` をカウンタ（初期値1）として使用し、`sum_loop` で
`rax += rcx; rcx++` を繰り返す。ループ継続条件は「加算前の `rcx` が10以下」である必要があるため、
インクリメント後の `rcx` と `10` を比較し `rcx <= 10` の間ループを継続する（`jle`）。
これにより `rcx = 1,2,...,10` が過不足なく加算され、`rax = 1+2+...+10 = 55` となった時点でループを抜け、
`sys_exit(rax)` で終了コードとして55を返す。

ビルド:
```
nasm -O0 -f elf64 -o sum.o sum.asm
ld -o sum sum.o
```

### デバッグ記録

当初 `cmp rcx, 11` としていたところ、`rcx=11` のときも `jle`（11<=11）が成立してしまい
もう一周余分にループが回って `rcx=11` まで加算されてしまい、終了コードが `66`（55+11）になる
バグがあった。`cmp rcx, 10` に修正し、`rcx<=10` を継続条件とすることで正しく55になることを確認した。
